# Octagons

A rotational construction of genus $g$ surfaces from $(g-1)$ octagons.

- `octagons.tex` — the note.
- `octagons.pdf` — the compiled note.
- `figures/group-symmetry.tex` — TikZ source of the octagon figure.
- `figures/group-symmetry.pdf` — the figure used by the note.

Build from this directory:

```sh
pdflatex octagons.tex
pdflatex octagons.tex
```
